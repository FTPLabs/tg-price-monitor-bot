# 🤖 Telegram Price Monitor Bot

Бот для мониторинга цен на товары с Wildberries, Ozon и AliExpress. Уведомляет пользователя, когда цена опускается до указанного уровня.

## Стек

- Python 3.11+
- aiogram 3.x
- aiohttp (асинхронные запросы)
- BeautifulSoup4 (парсинг)
- SQLite (хранение данных)

## Возможности

- ✅ Добавление товаров по ссылке
- ✅ Получение текущей цены в реальном времени
- ✅ Установка целевой цены
- ✅ Периодическая проверка (каждые 30 минут)
- ✅ Push-уведомление при снижении цены
- ✅ Список активных отслеживаний
- ✅ Поддержка WB, Ozon, AliExpress

## Запуск

```bash
# 1. Установить зависимости
pip install -r requirements.txt

# 2. Создать .env из примера
cp .env.example .env
# Заполнить BOT_TOKEN

# 3. Запустить
python bot.py
```
